# Blog Platform with Comments

Full-stack blogging platform with:
- User registration, login and JWT authentication
- Create, edit API, and delete blog posts
- Comment section
- RESTful APIs
- Persistent JSON database (`database.json`)
- Responsive frontend

## Run locally
1. Install Node.js
2. Open terminal in this folder
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## API
POST `/api/register`
POST `/api/login`
GET `/api/posts`
POST `/api/posts`
PUT `/api/posts/:id`
DELETE `/api/posts/:id`
POST `/api/posts/:id/comments`
